# Automated-Fetal-Biomterics-identification-using-Deep-Learning
this is a repository containing the scripts for training and creating models for Biometrics identification such as Head Circumference, Abdomen Structures,Abdomen Circumference and Femur Length
i created 4 Hybrid models using Architectures like Unet, Unet++,Faster RCNN, Attention-Unet and convex hull algorithm.
since i used a private dataset from a Hospital, i cannot display the code for Femur length and Abdomen circumference.
i have listed not the models but only the training scripts of head circumference and Abdomen structures.
HC dataset: HC18 dataset and Zendeley dataset
Abdomen structures: Mendeley dataset
